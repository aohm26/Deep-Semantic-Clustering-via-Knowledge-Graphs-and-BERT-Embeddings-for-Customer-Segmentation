This repository contains the implementation of the research paper entitled "Deep Semantic Clustering via Knowledge Graphs and BERT Embeddings for Customer Segmentation."

The proposed approach combines Knowledge Graphs, BERT-based semantic representations, and Deep Embedded Clustering (DEC) to perform semantic customer segmentation.

The implementation aims to reproduce the methodology and experimental results presented in the paper, paper DOI:10.1109/IC2SDA68097.2025.11331329.
